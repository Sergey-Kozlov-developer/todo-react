## **ToDo React** 🗂

- ✔️ [результат](https://sergey-kozlov-developer-todo-react-a9f5.twc1.net/)

- ⚔️ Стек технологий, которые я использую в этом проекте:
    - **React, SCSS, БЭМ**

**В приложении показана работа с:**

- useContext, useReducer
- добавлением/удалением/редактированием задач
- поиском
- фильтрацией
- сменой темы
- сортировкой

**примечание**

- в ветке todo-api-and-pagination реализован CRUD по задачам, подключение к [API](https://dummyjson.com/) и пагинация на MUI
  Данная ветка не была включена в production, т.к. API не позволяет полноценно использовать CRUD на своей стороне
